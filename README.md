Stylus is a Chrome extension that turns any webpage into a canvas you can edit. Select things on the page and hide them, rewrite them, or restyle them, the way you would in Figma. Stylus remembers your changes for each site and applies them every time you come back. It can also record what happens on a page as a video and turn screenshots into images ready to share.

## What it's for

**Make the sites you use every day calmer.** Hide cookie banners, ads, sidebars and sticky bars with one click (Focus mode), or click things away yourself. Switch a site to Dark, Sepia, Night or Reading mode, or set its background, text color and font. Stylus remembers it, so the site stays that way.

**Try a design change on the real page before writing code.** Select an element and change its layout, spacing, colors, type and shadows in the Design panel, or drag handles on the page to resize it and change its padding. Move elements around, edit text in place, and measure distances. Every change is listed, can be switched off, and can be exported as JSON.

**Record a quick walkthrough.** Record one element or the whole tab, Loom style, with a visible cursor, click ripples and the keys you press. The video is ready to download as MP4 when you stop.

**Share screenshots that look good.** Capture an element or the visible tab, then put it on a gradient or blurred background, in a window or browser frame, at the right size for X, Instagram, Stories or LinkedIn. Copy it or download a PNG.

**Keep your browser tidy.** Recordings and screenshots stay in the browser until you download them, and downloading moves them out. The Storage page shows everything Stylus keeps and lets you clear it.

## Features

### Editing on the page

- Select by clicking; Shift-click adds to the selection. Esc, Enter and Tab move to the parent, first child and next sibling. S selects every similar element, so one change styles all the cards in a list.
- Hide anything with Delete, or switch to the Zap tool and click things away one by one. Isolate hides everything except the selection.
- Edit text in place: double-click, type, press Enter.
- Drag handles on the selection: the edges and corner resize it, the green and orange handles change padding and margin (Alt changes all four sides), and the dot near the corner rounds it. Shift snaps to 8px.
- Move the selection with the arrow keys (Shift moves 10px), or drag it past its siblings to reorder it.
- Hold Alt and point at another element to see the distance between them. A selected flex or grid container shows its children, gaps and tracks.
- Right-click any element and choose Stylus to hide it, edit its text, style it or screenshot it, without opening edit mode first.

### Design panel and CSS

- Layout and flexbox alignment, size, margin and padding, typography, background, border, shadow, blur and opacity. Drag a field's label to change its value, or use the arrow keys.
- Write CSS for the selected element or for the whole site.
- Style the hover, focus or active state, or limit a change to one screen size (mobile, tablet, desktop).

### Themes and focus

- Presets: Dark, Dim, Sepia, Night, Mono, Contrast and Reading. Filter presets combine.
- Set the page background, text color, link color, font and zoom.
- Focus mode hides cookie banners, ads, popups, sidebars and sticky bars, and lists each one so you can bring it back.

### Layers and changes

- The Layers panel shows the page as a tree. Search it by name or CSS selector, and show or hide items.
- The Changes panel lists every change. Switch each one off, delete it, or export the site's changes as JSON and import them elsewhere.
- Undo and redo everything. Changes sync to other open tabs of the same site, and the power button shows the original page without losing them.

### Recording

- Record the selected element or the whole tab after a 3-2-1 countdown. The page stays usable while you record.
- The video shows a cursor, click ripples and the keys you press, and includes the tab's sound.
- Pause, stop or discard from controls next to the recorded element. When recording the whole tab, stop with Alt+Shift+S or the Stylus icon.
- The video is written to the browser's storage as you record, so a crash loses at most the last second. Interrupted recordings come back as Recovered.
- Watch, rename, download as MP4 or delete recordings in the Recordings page.

### Screenshots

- Capture the selected element or the visible tab. Stylus hides its own controls for the shot.
- Backgrounds: gradients, mesh gradients, solid colors, the screenshot itself blurred, or transparent.
- Frames: a window or a browser window with the page's address, light or dark.
- Sizes: Auto, 16:9, 1.91:1, 1:1, 4:5, 9:16 and 3:2.
- Padding, rounded corners, shadow, a glass edge, grain and a watermark.
- Copy to the clipboard or download a PNG at 1× or 2×. Each screenshot keeps its style, and new ones start from the last style you used.

### Storage and privacy

- Everything stays in your browser. Nothing is uploaded.
- Downloading a recording or screenshot saves it to your Downloads folder and then removes it from Stylus. Tick Keep a copy in Stylus to keep it instead.
- The Storage page (also the extension's Options page) shows the space used, every recording and screenshot with its size, unfinished recording data and site edits, and deletes single items or everything.

## Install

Stylus is not on the Chrome Web Store yet. Build it and load it unpacked.

```sh
pnpm install
pnpm build
```

1. Open `chrome://extensions` and turn on Developer mode.
2. Click "Load unpacked" and choose `packages/extension/.output/chrome-mv3`. The `.output` folder is hidden in Finder, so press Cmd+Shift+G in the file dialog and paste the full path.
3. Reload any tabs that were open before you installed the extension.

## Use

Press Alt+Shift+S, or click the Stylus icon in the toolbar, to turn edit mode on or off. Outside edit mode, Stylus applies your saved edits and shows no UI.

| Key | Action |
| --- | --- |
| V, H, T | Select tool, Zap tool (click to hide), Text tool |
| Click, Shift-click | Select one element, add to the selection |
| Double-click | Edit text (Enter saves, Esc cancels) |
| Esc, Enter, Tab | Select the parent, first child, next sibling |
| S | Select all elements similar to the current one |
| Delete | Hide the selection |
| Arrow keys, Shift+arrows | Move the selection by 1px, by 10px |
| Drag the selection | Reorder it among its siblings |
| Hold Alt and point | Measure the distance to another element |
| Cmd+Z, Cmd+Shift+Z | Undo, redo |
| L, D | Show or hide the Layers and Design panels |

To take a screenshot, click the camera in the toolbar and choose the selected element or the visible tab, use Screenshot in the bottom bar, or right-click any element and choose Stylus, then Screenshot this element. The editor opens in a new tab.

To record, click the record button in the toolbar and choose the selected element or the whole tab, or use Record in the bottom bar. While recording an element, the controls sit next to it; for the whole tab they stay out of the video, so stop with Alt+Shift+S or the Stylus icon. Esc cancels during the countdown.

The bar at the bottom of the screen shows the selected element's ancestors, quick actions (Similar, Isolate, Edit text, Hide), and the state and screen size that new style edits apply to.

## Develop

```sh
pnpm dev        # opens Chrome with the extension loaded and hot reload on
pnpm build      # writes the extension to packages/extension/.output/chrome-mv3
pnpm typecheck
pnpm test       # unit tests for the op model, CSS compiler, and undo history
pnpm e2e        # builds the extension, then runs the Playwright suite against it
```

### End-to-end tests

The suite in `packages/extension/e2e` loads the built extension into Chromium with a fresh profile for each test and drives it with the mouse and keyboard. It uses three fixture pages: an ordinary page, a single-page app that re-renders its content, and a hostile page with a full-screen overlay at the maximum z-index and `!important` style resets.

The 116 tests check edit mode, the right-click menu, the on-canvas handles, nudging and reordering, measuring, selection and keyboard navigation, every tool, the Layers search, each Design control, hover and breakpoint edits, all theme presets, Focus mode, the Changes panel, undo and redo, persistence across reloads, loading without a flash of the original page, per-site isolation, sync between tabs, edits surviving re-renders, recording (checking the saved video's size and pixels, crash recovery and cleanup), screenshots (checking the exported PNG's size, colors and transparency), downloads, and the Storage page. One test is a full session driven only by mouse moves, clicks, drags, held keys and typing.

```sh
npx playwright install chromium            # once, or set CHROME=/path/to/chrome
pnpm e2e                                   # headless run, HTML report in packages/extension/e2e/report
pnpm --filter @stylus/extension e2e:ui     # Playwright UI mode for debugging
```

## How it works

Stylus stores every change as a small JSON record called an `EditOp`. There are six kinds: `style`, `hide`, `text`, `move`, `rawCss`, and `preset`. A site's ops live in `chrome.storage.local` under its origin.

On page load, the content script reads the site's ops and compiles the style, hide, and preset ops into one `<style>` element. It holds the first paint until that finishes, so hidden elements never flash. A `MutationObserver` applies text and move ops again whenever the page re-renders them.

Recordings and screenshots live in IndexedDB on the extension's own origin. A recording is captured with `chrome.tabCapture`, cropped and encoded in an offscreen document, and written to IndexedDB a chunk at a time. Screenshots come from `chrome.tabs.captureVisibleTab`, and one canvas renderer draws both the editor preview and the exported PNG.

```
packages/shared      EditOp schema (zod), op-to-CSS compiler, edit helpers, undo history
packages/extension   the WXT extension
  entrypoints/background.ts        toolbar button, keyboard shortcut, badge
  entrypoints/content/engine       storage and state, style engine
  entrypoints/content/canvas       overlay, element picker, toolbar, bottom bar
  entrypoints/content/panels       Layers, Design, Theme, and Changes panels
  entrypoints/offscreen            records the captured tab, cropped to the target
  entrypoints/recordings           the recordings library page
  entrypoints/capture              the screenshot editor
  entrypoints/options              the Storage page
  lib/shot-render.ts               draws a styled screenshot (used for both preview and export)
  e2e                              Playwright tests and fixture pages
```
